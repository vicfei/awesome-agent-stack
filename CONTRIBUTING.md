# Contributing

- **Add/fix an entry**: PR against `atlas/entries/data.mjs` — editorial fields only (`what`, `mechanism`, `status`, `adopted`, `verified`, `note`). `atlas/metrics.json` is machine-written; hand edits are reverted.
- **Mechanism notes** must come from reading the source or running the thing — set `verified: "<date>"`. Doc-level summaries stay unverified; that's allowed and labeled.
- **Corrections** (wrong mechanism, dead project, miscategorized): issues get priority, target 72h first response.
- See EDITORIAL-POLICY.md for the full rules (same ruler for everyone; no paid placement).
